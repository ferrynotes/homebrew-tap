# Ferry for Homebrew

[Ferry](https://ferrynotes.com) is sticky notes on the desktop, in sync on
every device you own. This tap installs the Mac app, the same notarized
download as on [ferrynotes.com/download](https://ferrynotes.com/download#mac):

```sh
brew install --cask ferrynotes/tap/ferry
```

Ferry updates itself once installed, so `brew upgrade` leaves it alone.
